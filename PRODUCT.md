# Lost & Found

A five-minute cooperative browser mystery for two classmates at the same table.
Each person has a different folder of evidence. Publishing evidence and assembling
a shared chronology lets them explain a missing exhibition object. Solo mode gives
one visitor both folders and a complete, independent experience.

## Scope
One original fictional case, The Blue Hour; eight clues; four timeline events;
one evidence-backed conclusion; persistent investigations and an activity record.
The live implementation supports two-player investigations. C9 develops shared
behaviour; C10 adds a logs-only classroom exercise. Their human reflections and
the final portfolio remain distinct from automated technical verification.

## Quality claims
- A new visitor can start without an account and understand the next action.
- Both folders are necessary to confidently explain the cooperative case.
- Facts are in accessible text; no answer depends on pixels or hearing.
- A successful save is a database acknowledgement, not a browser animation.
- No silent overwrite when two people rearrange a shared timeline.
- Work remains after a restart or redeployment using the same volume.
- Five minutes is a design target pending human playtests, not a measured claim.

The student must review enjoyment and the personal written account. The agent
can claim only actual implementation and automated/browser verification.
